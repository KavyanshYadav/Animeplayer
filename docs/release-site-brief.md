# Animeplayer release site

The audience is Android TV viewers deciding whether to install Animeplayer. The site links to the official public GitHub APK and explains what the public build includes. The stack is static HTML, CSS, and JavaScript.

The release page uses an ink background, the app’s rounded Nunito typography, and a lavender download button. A large capture of the TV interface sits next to the title at desktop widths. On phones the same download action comes before the capture. The screenshot gallery is the main interaction and switches between the featured screen, browsing, episodes, and settings with click or arrow keys.

Screenshots come from the Animeplayer Android TV emulator. The Home captures use the TMDB-enabled build and are labeled accordingly. The public APK and compatibility details come from the Android TV 1.1 GitHub release.
